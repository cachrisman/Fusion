summary: Add task retry/pause/refine/duplicate, agent edit, model list, research, and trait-list tools to `fn mcp serve`.
category: feature
dev: Extends the curated `fn mcp serve` operator MCP registry (`packages/cli/src/mcp-server/tools.ts`) with 15 base-tier tools: task lifecycle (`fn_task_retry`, `fn_task_unarchive`, `fn_task_pause`, `fn_task_unpause`, `fn_task_refine`, `fn_task_duplicate`), agent edit (`fn_agent_update`, `fn_agent_set_instructions`), model discovery (`fn_models_list`), the governed research pipeline (`fn_research_run`/`fn_research_list`/`fn_research_get`/`fn_research_cancel`/`fn_research_retry`), and workflow-trait discovery (`fn_trait_list`). Every tool dispatches to the same `@fusion/core`/`@fusion/engine` domain operation the pi-extension `fn_*` handler uses (`fn_task_retry` additionally reuses the shared `buildAutoPauseClearPatch`/`buildManualRetryResetPatch`/`isInReviewMissingWorktreeSessionStartFailure` helpers so its retry classification cannot drift); the three research availability/serialization helpers were exported from `extension.ts` (added `export` only, no behavior change) for reuse. `fn_models_list` is the one net-new tool — constructs a `ModelRegistry` the same way `commands/dashboard.ts` does, with a stderr-only (never `console.log`) provider-registration log callback since MCP stdout is the protocol channel. All 15 are base-tier (not `--allow-destructive`-gated); base registry count 49 → 64, combined 60 → 75, destructive tier unchanged at 11 — enforced by `registry-invariants.test.ts`'s Invariant G.
